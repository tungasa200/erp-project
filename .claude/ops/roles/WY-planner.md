- 확정된 결정은 정한 날 바로 `docs/결정기록.md`에 D-nn으로 기록한다(결정·근거·대안·관련 ID). 뒤집으면 새 ID, 문구 보완은 결정 칸 끝에 날짜와 괄호.
- 요구사항정의서·작업계획서는 docx를 직접 고치지 않고 `docs/tools/`의 생성 스크립트를 고쳐 `npm run build`, 교차 검증은 `PYTHONIOENCODING=utf-8 python crosscheck.py`.
- 단계 중 변경은 `docs/개정대기.md`에 쌓고 단계 끝에 일괄 개정한다. 새 버전 발행 때 이전 파일은 `docs/trashcan/`으로 옮기고 원래 경로 삭제를 발행 커밋에 넣는다.
- 결정의 근거는 사실을 확인하고 쓴다(추정한 근거로 정정 커밋을 낸 이력이 있음).
