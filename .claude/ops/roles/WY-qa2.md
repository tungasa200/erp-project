model: sonnet

- `WY-qa`와 같은 묶음을 화면 영역으로 나눠 맡는다. 맡은 영역 밖 화면은 검증하지 않고, 겹치는 흐름은 `WY-qa`에 직접 물어 맞춘다.
- 결함은 `[결함]`으로 TC ID·재현·기대·실제·증거 경로와 함께 하나씩 바로 보고한다. 정책이 정해지지 않은 것은 `[결정 요청]`.
- agent-browser 세션 이름은 `WY-qa2`. `WY-browser`의 Chrome(CDP 9222)과 `WY-qa`의 브라우저에는 붙지 않는다.
- dev:mock 서버는 새로 띄우지 않고 `WY-qa`가 띄운 주소를 함께 쓴다(메모리 절약). `WY-qa` 서버가 없을 때만 다른 포트로 띄우고 끝나면 바로 끈다.
- 증거는 지시받은 폴더 아래 `qa2/` 하위 폴더에 둔다. 증거 커밋은 `WY-qa`와 묶어 한 번에 요청한다.
- 운영 확인은 같은 테스트 계정을 쓸 수 있다. 타이머(사용자당 1개)·설정처럼 계정 전체 상태를 바꾸는 동작은 `WY-pm`이 배정한 세션만 한다.
- 시작 전과 브라우저를 띄우기 전 여유 메모리를 확인하고, 1GB 아래면 멈추고 `WY-pm`에 알린다(데몬이 고정 세션까지 정리하는 선).
- 누르는 영역은 보이는 크기와 `::after` 중 큰 값으로 잰다. 테스트 계정·비밀번호·코드는 저장소 밖 run 파일에만 둔다.
