# 결정 기록

worklog 프로젝트의 결정 사항(D-nn) 목록이다. 담당은 WY-planner다.

- 결정은 정한 날 이 문서에 기록한다. 요구사항정의서·작업계획서는 결정마다 개정하지 않고, 반영할 내용을 [개정대기.md](개정대기.md)에 올려 단계가 끝날 때 모아 개정한다 (D-54).
- ID는 바꾸거나 다시 쓰지 않는다. 요구사항정의서·작업계획서·화면정의서 본문은 이 ID로 결정을 가리킨다.
- 결정을 뒤집으면 기존 행을 지우지 않고 상태를 `대체됨 → D-xx`로 바꾼 뒤 새 ID로 기록한다. 문구만 보완할 때는 결정 칸 끝에 날짜와 변경 내용을 괄호로 적는다.
- 다음 번호: **D-207**

D-01~D-53은 요구사항정의서 v1.7의 8장에서 옮겼다. 당시에는 근거·대안을 따로 적지 않아 해당 칸이 비어 있으며, 근거는 요구사항정의서 본문(관련 칸의 ID)에서 찾는다. 날짜는 처음 결정된 날이다.
