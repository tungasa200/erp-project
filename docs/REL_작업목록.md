## 출시 기준

아래가 모두 되면 출시한다(작업계획서 5.1 마일스톤 '출시').

1. 처리방침·이용약관의 빈칸이 모두 채워지고 자체 점검을 반영해 시행일과 함께 게시됨(전문가 검토는 출시 후, D-188), 가입 동의 확인이 동작함 (NFR-10)
2. 실기기(Android Chrome, iPhone Safari)에서 휴대폰 전 과정(기록 → 하루 마감 → 내보내기)·PWA 설치·웹 푸시가 통과함 (P4 완료 기준, NFR-06·07)
3. 성능 기준 통과: 일반 조회 API 95% 500ms 이내, 월간 일지 생성 3초 이내, 하루 마감 60초 이내 (NFR-01·12)
4. 남은 결함 중 '높음'·'중간'이 0건이고, REL 회귀 QA(운영)가 통과함
5. 배포 직후 502 같은 배포 중단이 없거나, 없앨 수 없으면 점검 모드로 가릴 절차가 정해짐
6. 외부 감시 도구 재검토(D-35)가 결정되고 그 결과가 처리방침에 반영됨 — 충족: 도입 안 함(D-191), 처리방침 변경 없음
7. 검색 노출이 막혀 있음(링크를 아는 사람에게만 공개, D-186)
8. feature/REL이 main에 병합·운영 배포되고, 사용자가 출시 판정 카드로 승인함 🙋
