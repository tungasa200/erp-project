# 개정 대기 목록 (화면정의서·화면 목업)

다음 개정 때 화면정의서와 화면 목업 캔버스에 반영할 항목이다. 담당은 WY-design이다.

- 단계가 진행되는 동안에는 항목을 추가만 한다. 화면정의서는 화면 내용이 실제로 바뀔 때만, 단계가 끝날 때 모아 발행한다. 기준 문서 버전만 바뀐 것으로는 발행하지 않고 다음 화면 변경 때 함께 반영한다.
- 구현을 막는 화면 변경만 예외로 바로 발행하며, 이때도 WY-pm에 먼저 묻는다.
- 결정은 [결정기록.md](결정기록.md)에 D-nn으로 기록되며(WY-planner 담당), 여기에는 화면정의서·목업의 어느 곳을 고칠지만 적는다.
- 개정에 반영한 항목은 지운다.
- 항목 형식: `날짜 · 출처 · 관련 ID` 다음 줄에 반영 위치(문서·장·ID)와 내용.
