F4. 빠른 입력 Esc·비우기(Q1)

글이 있으면 입력칸 오른쪽에 [×](44×44, 이름 "입력 지우기")가 생긴다. Esc는 포커스만 빼고 글을 남긴다(UX-COM-01 구현과 같음). 지운 뒤 되돌리기는 두지 않는다: [×]는 사용자가 겨냥해 누르는 동작이라 실수 비용이 Esc보다 낮다.
