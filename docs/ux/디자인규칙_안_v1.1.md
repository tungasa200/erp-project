## ① X-04 Esc·되돌리기 — [결정됨] Q1 ①

### 규칙 안 (판정 그대로)
1. **Esc는 사용자가 쓴 글을 말없이 버리지 않는다.**
   - 저장 단계가 없는 입력(빠른 입력 SCR-COM-02, 모바일 시트 SCR-MOB-01, 팔레트 입력)
     - Esc는 열린 것을 닫거나 포커스만 뺀다. 글은 남긴다.
     - 비우기는 입력칸 안 [×] 버튼으로 한다. 글이 있을 때만 보이고, 누르는 영역은 44px이다.
   - 저장 단계가 있는 창(일정 상세 SCR-CAL-07, 기록 추가·수정 창 등)
     - 처음 값과 달라진 것(dirty)이 있으면 Esc를 눌렀을 때 창 안에 한 줄을 띄운다.
     - 문구: "고친 내용이 있어요. 버리고 닫을까요?" + [계속 편집](포커스) · [버리고 닫기]
     - 겹친 모달은 쓰지 않는다. Esc를 한 번 더 누르면 [계속 편집]과 같다.
   - 바깥 누르기는 누름(pointerdown)과 뗌(pointerup)이 모두 창 바깥일 때만 닫기로 친다. 닫을 때 dirty 확인은 Esc와 같다.
2. **데이터를 바꾸는 동작은 5초 되돌리기 토스트를 띄운다.**
   - 기존 대상(SCR-COM-04 states)에 다음을 더한다.
     - 일지 실적·계획 줄 삭제(LOG-101)
     - 타이머 정지(COM-32): 되돌리면 타이머가 이어서 돈다. 1분 미만이라 버려지는 경우에도 토스트는 띄운다.
3. **되돌리기의 기준은 보이는 [되돌리기] 버튼이다.**
   - Ctrl/⌘+Z는 토스트가 떠 있고 포커스가 글 입력칸이 아닐 때만 연결한다. 빈 입력칸은 글 입력칸으로 보지 않는다.
   - 토스트가 사라지면 Ctrl+Z 연결도 끝난다.
4. **결과가 문서 상태인 동작(일지 확정)**: 토스트를 쓰지 않는다. 완료 창 안에 상시 [확정 해제]를 둔다(⑤의 Q3).

### X-02 주 버튼 규칙 안 (판정 안 A + C)
- **한 시야에 키 컬러 채움은 하나다.**
- 목록 안 반복 동작은 accent-soft 바탕 + accent-ink 글자로 한다. 글자 대비는 4.5:1 이상이다.
- accent-soft 면의 경계
  - accent-soft는 바탕과 대비가 1.03~1.1:1이라 경계가 보이지 않는다.
  - 그래서 동작이 둘 이상인 행이나 버튼으로 읽혀야 하는 면에는 **1px `--color-accent` 윤곽**을 준다. 윤곽 대 accent-soft는 3.86~10.8:1로 전 프리셋이 통과한다(조정 프리셋 기준).
- 상태 강조는 숫자 색으로만 한다. 면을 칠하지 않는다.
- 위반을 고칠 곳: HOME(채움 1280에서 3, 390에서 4), REC-59, SET-82(설정 채움 2), ONB-88(랜딩 CTA 2: 랜딩은 Persuade 화면이라 주 CTA만 채움, 둘째는 윤곽), LOG-44

### X-03 위험색
- 위험색(`--color-danger`)을 쓰는 곳은 두 가지뿐이다.
  - ① 되돌릴 수 없는 동작의 버튼: 탈퇴, 영구 삭제
  - ② 기한 초과 상태의 글자·작은 배지
- 면 채움은 ①의 마지막 확인 버튼에만 쓴다.
- 확정 해제는 중립 채움 + 결과 한 줄("일지는 초안으로 돌아가고 내보낸 파일은 그대로예요")이다. 보관은 중립 보조 버튼이다.
- 홈 "지금" 선은 키 컬러다(HOME-05).
- 일정 삭제는 중립 + 5초 되돌리기다(ux3 이견에는 X-04 규칙 2와 토스트 멈춤이 답이다).

### X-03a 한 줄에 놓인 버튼 짝 (2026-10-13 보충, 사용자 지적: 보관함 [복원]·[영구 삭제] 모양이 다름)
- 대상: 목록 행·창 바닥·확인 줄처럼 **한 줄에 버튼이 둘 이상** 놓이는 곳.
- **틀은 같게**: 한 줄 안의 버튼은 모서리·높이·좌우 여백·글자 크기·굵기·테두리 두께가 같다.
  - 알약(`--radius-pill`). 목록 안 반복 동작이 이미 다른 모서리로 맞춰져 있으면(확인 대기 패널 `--radius-input`) 그 줄 안에서 같기만 하면 된다.
  - 높이 44(`--size-touch`). 행이 좁아 보이는 높이를 줄이면 36 + `::after` 44.
  - 좌우 `--space-4`, 글자는 행 `--text-sm`·창 바닥 `--text-md`, `--weight-title`.
  - 테두리 1px은 `box-shadow: inset 0 0 0 1px …`로 모든 버튼에 둔다(면 버튼은 면과 같은 색). 그래서 폭·높이가 어긋나지 않는다.
- **색은 역할로 나눈다**:
  - 주 동작(그 줄에서 기대하는 동작: 복원·했어요 등): `--color-accent-soft` 면 + `--color-accent-ink` 글자. 창의 최종 [저장]만 `--color-accent` 채움.
  - 중립 보조(보관·취소·계속 편집·되돌리기 있는 삭제): `--color-surface` 면 + `--color-border` 테두리 + `--color-text-strong` 글자(업무 상세 [보관]이 기준 모양).
  - 위험(되돌릴 수 없음: 영구 삭제·기록 삭제·버리고 닫기): `--color-surface` 면 + `--color-danger` 글자 + 테두리 `color-mix(in srgb, var(--color-danger) 40%, var(--color-surface))`. 마우스 올림·누름은 `--color-danger-soft` 면. **위험색 면 채움은 확인 창 마지막 버튼에만**(X-03).
  - 꺼짐: 같은 틀, 글자 `--color-disabled`, 테두리 `--color-border`, 면 `--color-surface`.
- **순서**: 행에서는 주 동작 먼저, 위험 동작이 맨 끝(오른쪽), 사이 `--space-2`. 창 바닥은 지금처럼 삭제류를 왼쪽에 두고 빈칸으로 띄운 뒤 [취소]·[저장].
- 글자만 있는 버튼(링크 모양)은 문장 안 이동·보조 링크에만 쓰고, 버튼 짝에는 쓰지 않는다.
- 예외: 시스템(404 등)·인증 화면의 큰 버튼 줄(높이 50~52, 좌우 `--space-5`)은 그 틀을 그대로 쓰고, 그 줄 안에서 같게 맞춘다(pm 결정 2026-10-13).
- [취소]류(`.secondary`)도 앱 전체에서 중립 윤곽이다. 고대비 모드(`forced-colors: active`)에서는 inset 그림자가 사라지므로 `border: 1px solid ButtonText`로 경계를 남긴다.

### X-11 두 길 + 점선
- 화면 안 [+]는 조건을 미리 채운 같은 빠른 입력으로 연다.

  - 블록 낭독기 이름에 "계획"을 넣는다.
  - CAL-93 끌기 ghost는 점선으로 한다.

  - `!1`처럼 문법 기호 뒤 값이 맞지 않으면 경고 칩("우선순위는 !1~!3이 아니라 …")을 띄운다.
  - COM-06: 없는 프로젝트라 Enter가 막히면 미리보기 문구는 "Enter를 누르면 새 프로젝트를 만들지 물어요"로 한다(동작과 같게).

### X-12 모션·hover·직접 조작 (순서대로)
1. hover는 `@media (hover:hover) and (pointer:fine)` 안에서만 준다. 이것을 먼저 한다.
2. 누름 피드백은 배경 한 단계 어둡게, 0ms로 한다. scale(0.97)은 작은 원형 버튼(+, 타이머)만 쓴다.
3. 키보드로 여는 것(팔레트·칩 메뉴·도움말)은 모션 0이다.
4. 토스트·시트 진입은 opacity + translate 180ms ease-out 이하다. 퇴장은 120ms 이하거나 즉시다.
5. 직접 조작(끌기·길게 누르기·시트 끌기)
   - 손가락을 0ms로 따라온다.
   - 잡히면 즉시 `--shadow-1` + 불투명도 0.9를 준다.
   - 제자리로 돌아갈 때만 200ms `cubic-bezier(0.32,0.72,0,1)`이다. 옮기기에 성공하면 즉시 놓인다(MOB-02).
6. `touch-action: manipulation`을 앱 전체에 준다.
7. `prefers-reduced-motion`이면 4·5의 이동을 없애고 opacity만 남긴다.
- 포커스 표시(COM-34): 입력도 전역 `:focus-visible` 2px 윤곽선 하나로 통일한다. 테두리 색만 바꾸는 방식은 없앤다.

### X-13 표기
- 날짜·시간은 화면정의서 표기("10/8(목)", "14:00 – 15:00")를 따른다.
  - 공용 함수 한 곳에서 만든다. 내부는 `Intl.DateTimeFormat(…, { timeZone: 사용자 시간대 })`이다.
  - 일지 문서 서식도 같은 함수를 쓴다.
  - 기기 시간대를 쓰는 곳(SYS-02)은 고친다.
- placeholder: 예시 패턴이면 "예: …", 지시문이면 문장 그대로 둔다. 끝에 "…"를 붙이지 않는다.
- 진행 중 문구는 "불러오는 중…"·"저장 중…"이다(말줄임표 한 글자 "…").
