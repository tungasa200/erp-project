# 업무일지 숨김 — 문안 v1

- 작성 WY-design, 2026-10-12. 근거: 사용자 결정 카드 20261012-2215. worklog는 업무 기록 도구로만 두고 업무일지는 사용자에게서 숨긴다. 코드·API·데이터는 그대로 둔다(나중에 서류·결재 서비스로 옮김).
- 정해진 것: ① 하루 마감 창은 남기고 '일지'라는 말만 지운다(확인 대기 → 내일 계획 → 이슈 → [오늘 마감]). 창 안에서는 지금처럼 일지를 확정하고, 일지 미리보기 칸은 숨긴다. ② 내보내기(PDF·Word·Excel)는 숨긴다. ③ 남는 '일지' 문구는 기록 도구 문구로 바꾼다. 처리방침·약관은 데이터 설명을 그대로 두고 소개 문구만 바꾼다.
- 범위: `frontend/src`에서 사용자에게 보이는 글자(주석·테스트·mock 제외), 백엔드가 만드는 알림·파일 문구. 인증번호·비밀번호 재설정 메일에는 '일지'가 없다(해당 없음).
- 담당: `src/stats`·`src/landing`·`src/calendar`는 **F2**(WY-frontend2), 나머지는 **F1**(WY-frontend). **BE**는 백엔드 문구로, 이번에 바꿀지는 pm이 판단한다.
- 표기: **숨김**은 화면에서 빼고 코드는 둔다. "→"는 새 문안이다.

## 남는 문제 (pm 판단)

1. **넘긴 내일 계획·이슈를 다시 볼 곳이 없다.** 일지가 숨겨지면 하루 마감에서 넘긴 계획과 남긴 이슈를 고치거나 볼 화면이 없다(3-2에서 계획 지우기 길도 사라짐). 추천: 이번엔 그대로 두고, 필요하면 다음 하루 마감 2단계에 "어제 넘긴 계획" 목록을 보여 주는 안을 따로 검토.
2. **설정 프로필 탭(SCR-SET-01)**: 이름·소속·직책은 일지 머리에만 쓰인다. 추천: 탭 숨김(4-7, 4-14 함께).
3. **이메일 인증 이유**: 지금 인증이 필요한 곳은 내보내기뿐이다. 비밀번호 재설정은 미인증 계정도 되고 재설정하면 인증 처리된다(`PasswordResetService`). 그래서 '비밀번호를 잊었을 때 필요' 같은 다른 이유를 대면 사실이 아니다. **추천: 미인증 배너(4-12)와 설정 계정의 미인증 줄(4-9)을 숨기고, 가입 안내(4-15)의 뒤 문장을 지운다.** 인증 화면(SCR-AUTH-08)과 API는 그대로 둔다(가입 직후 인증 단계는 지금처럼).
4. **약관 272·322행**: 내보내기를 숨기면 "언제든지 파일로 내보내 보관"이 사실과 달라진다. 약관 변경이라 WY-planner·사용자 확인이 필요하다(지금은 데이터 설명이라 그대로 둠).
