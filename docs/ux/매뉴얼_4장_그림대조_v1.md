# 매뉴얼 4장 그림·원고 대조 v1 (WY-design, 2026-10-13)

대상: `docs/manual/04-하루따라하기.md`와 `images/04/` 18장. 원고 본문, 끝의 촬영 목록 주석과 그림을 하나씩 대조했다.

## 공통 원인

- 촬영 시각이 00:2x이다. 웹 홈이 배경인 그림(HOME-01·COM-02·HOME-02·LOG-03)마다 인사 '늦은 시간이에요'와 '지금 00:26~00:29' 줄이 보여, 아침·18시 이야기와 어긋난다.
- 데이터가 원고의 화요일과 다르다.
  - 원고: 초대장 시안 검토 10–11, 행사장 견적 비교 14–16, 외부 협력사 미팅 16–17, 메일 정리 17:30–18.
  - 그림: 협력사 일정 조율 00:00–00:10, 팀 업무 분담표 정리 00:10–00:20, 행사 포스터 문구 정리 10–11, 설문 응답률 점검 14–15.
- 홈 PC 다시 디자인(D-231·카드 1620 v2, 본문 폭 912 이상이면 3열)이 구현되면 HOME-01_W 그림과 원고 표의 '오른쪽 열' 설명이 함께 낡는다.

→ 다시 찍기는 홈 v2 구현 뒤 한 번에 하는 것이 좋다. 그때 시드 데이터를 원고의 화요일(어제 확인 대기 1건 + 오늘 1~2건)로 맞추고, 아침과 18시 이후에 나눠 찍는다(촬영 WY-qa).
