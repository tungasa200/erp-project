### ③ 오늘 일정 행 (배지 사양은 그대로, 면·테두리만) [결정 3]
- 지금 계획 행과 완료 행이 같은 면(`--plan-tint`)이라 하루의 진척이 안 보인다. 디자인 규칙 "점선은 아직 실제가 아닌 것(계획 일정)"에도 맞지 않는다. 구현을 고칠 것.
- 테두리는 행 기본 `border: 1.5px solid transparent`(지금 1px)로 두고 상태마다 모양·색만 바꾼다. 높이는 min-height 44 그대로.
- 앞으로 할 일정(기록 없음, phase 미래): `--color-surface` 면 + `border: 1.5px dashed var(--plan-base)`. 글자 `--color-text`.
- 진행 중: `--plan-tint` 면 + 지금처럼 `inset 0 0 0 2px var(--plan-base)`.
- 했어요(CONFIRMED): `--plan-tint` 면, 테두리 투명(1.5px transparent), 이름 글자 `--plan-ink`(프로젝트 ink, 프로젝트가 없으면 `--color-accent-ink`). 배지 "✓ 했어요"는 그대로. 화면정의서 2.3 "확정 = 진한 채움 + 흰 글자"를 바꾼다(캘린더도 같음, 3a).
- 안 했어요 글자: 지금 `--status-skipped-text`(#8A8FA3)는 회색 면 위 2.8:1이라 `--color-text-muted`(5.1:1)로, 시간 칸 opacity 0.85도 이 행에서는 1(캘린더 skipped와 같음). 구현을 고칠 것.
- 확인 대기·안 했어요: 지금 그대로(노란 면+테두리 / 회색 면+취소선).
- 끝났는데 기록 없음(끝남): surface 면 + 1px `--color-divider` 실선.
- 행 모양(배지 칸 56·시간 88·버튼 X-03a)은 바꾸지 않는다. 배지 칸 56은 Pretendard에서 가장 긴 배지("안 했어요"·"확인 대기")와 같은 폭이다(시스템 글꼴로 바뀌면 64까지 늘어 시간과 붙는다). `--plan-ink` 변수는 `--plan-base`·`--plan-tint`처럼 행 style로 넘긴다(`projectColor().ink`).

### ③a 캘린더 블록 (같은 상태 규칙, WY-frontend2 구현 중인 기록 상태 표현에 적용)
- 테두리 두께는 지금 것 그대로: 주·일 블록 2px, 월 칩·종일 막대 1.5px. 모양·색만 상태로 바꾼다.
- 예정(계획): `--color-surface` 면 + dashed `--block-base`, 글자 `--block-ink`. **지금의 옅은 면(`--block-tint`)에서 흰 면으로 바뀐다**: 했어요가 옅은 면이 되므로 둘을 면으로도 가른다.
- 진행 중: `--block-tint` 면 + solid `--block-base`.
- 확인 대기: 지금 그대로(`--status-pending-bg` 면 + solid `--status-pending-border` + "!").
- 했어요: `--block-tint` 면 + solid, 테두리 색 `--block-tint`(면과 같아 안 보이고 크기는 그대로), 글자 `--block-ink`, 제목 앞 "✓".
- 안 했어요: 지금 그대로(회색 면 + `--color-border` 실선 + 취소선 + muted 글자).
- 고대비(forced-colors): 면이 지워지므로 예정=점선, 진행 중·했어요·안 했어요=실선, 확인 대기=이중선 4px(지금 규칙), 글자 표시(✓·!·취소선)로 가른다.

### ④ 남은 업무: 거의 그대로
- 마감 묶음·날짜 칩 색은 목업과 같다. 바꾸는 것은 하나다. 일반 행 면을 `--color-accent-faint`(#F6F5FD)에서 목업과 같은 회백 `color-mix(in srgb, var(--color-ground) 50%, white)`(≈#F9FAFD)로 바꾼다. 마감 초과 행은 지금 그대로. 연보라가 화면 전체에 깔려 있는 것을 줄이고, accent를 "누를 것"에만 남긴다.

### ⑤ 오늘 마감 카드: 진행 막대 되돌림

  - `aria-hidden="true"`. 같은 정보는 옆 글 "확정 기록 1건 · 다음 근무일 계획 0건 · 이슈 없음"이 말한다.
