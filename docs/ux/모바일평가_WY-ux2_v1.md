## 2. 지적

### UX-M-TASK-44 업무 상세 패널이 대화창으로 알려지지 않고 뒤 화면이 살아 있음
- 화면: SCR-TASK-02 · 폭: 390 · 축: 5·M4 · 심각도: 중간 · 구분: 구현 차이
- 문제: 390에서 상세는 `position: fixed; inset: 0`(tasks.module.css:758) 전체 화면 ASIDE인데 `role="dialog"`·`aria-modal`이 없고 뒤 목록·하단 탭에 `inert`·`aria-hidden`이 없다. 패널에 `overscroll-behavior`도 없다.
- 영향: 화면 읽기·키보드 사용자는 보이지 않는 뒤 목록과 하단 탭으로 Tab·가상 커서가 빠져나간다. iOS에서 패널 끝까지 스크롤하면 뒤 목록으로 스크롤이 이어질 수 있다.
- 제안: 390에서는 패널을 모달 시트로 다루어 `role="dialog" aria-modal="true"`, 뒤 영역 `inert`, 패널에 `overscroll-behavior: contain`. 뒤로 가기로 닫히는 지금 동작(M10 통과)은 그대로 둔다.
- 근거: WCAG 1.3.1·2.4.3, web-design-guidelines "overscroll-behavior: contain in modals/drawers/sheets", Google Calendar 모바일의 일정 상세 시트.
- 증거: TASK-02-390.png. 스냅숏에 패널과 함께 `region "업무 목록"`, `navigation "하단 탭"`이 함께 나옴. 패널 클래스 `_panel_m1vwc_482`.
