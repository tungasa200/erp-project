## 2. 국외 이전 고지 (제28조의8 제1항 제3호·제2항, D-33·D-174)

처리 위탁·보관을 위한 국외 이전은 제2항의 사항을 처리방침에 공개하면 별도 동의 없이 할 수 있다. 제2항 사항별 점검:

| 사항 | 3장 표 | 판정 | 할 일 |
|---|---|---|---|
| 이전되는 항목 | '이전 항목' 열 | ✅ | |
| 국가, 시기·방법 | '국가', '시기·방법' 열 | ✅ | Vercel 로그·계정 데이터 저장 국가는 공식 문서로 확인 못 함(초안 주석) — 검토 대상 |
| 이전받는 자의 명칭과 연락처 | '이전받는 자' 열에 명칭만 | ❌ | **연락처 열 추가 필요**: Railway·Vercel·Google·푸시 운영사(Apple·Mozilla·Microsoft)의 개인정보 문의 연락처를 각 사 공식 개인정보 처리방침에서 확인해 적는다(짐작으로 쓰지 않음, WY-search 조사 가능). REL-01에 포함 |
| 이용 목적, 보유·이용 기간 | '목적', '보유 기간' 열 | △ | Google(Gmail 보낸편지함) 보유 기간이 '운영자가 지울 때까지'로 끝이 없음 — 정기 삭제 규칙을 정할지 결정 후보 |
| 거부 방법·절차·효과 | 표 아래 문단 | ✅ | 탈퇴로 거부, 거부하면 이용 불가 |
| 푸시 서비스 운영사 해당 여부 | 표 마지막 행 | △ | 해당한다고 보고 고지함(보수적). 해당 여부 판단은 출시 후 전문가 검토(D-188) |
| 가입 화면 안내 | 3장 첫 문단이 '가입 화면 안내'를 말함 | △ | 가입 화면(SCR-AUTH-03)에 국외 이전 안내와 처리방침 링크가 실제로 있는지 REL-03 QA로 확인 |

## 6. 출시 전 남은 할 일 (REL-01·03)

1. 처리방침 3장 표에 이전받는 자별 연락처 열 추가(각 사 공식 처리방침에서 확인) — ❌ 항목, 출시 전 필수
2. Vercel 환경변수 VITE_CONTACT_EMAIL 설정(WY-browser 또는 사용자)과 앱 문안의 연락처 자리 연결(WY-frontend2)
3. 공고일·시행일 확정(REL-03)
4. 가입 화면의 국외 이전 안내·처리방침 링크, 연락처 표시를 운영에서 QA(REL-03)

출시 후 전문가 검토로 넘길 것: △ 항목 중 파기 절차 문단, 위탁 고지 겸용, 브라우저 저장소 한 줄, 관리적 보호조치, 푸시 운영사 해당 여부, Gmail 보낸편지함 보유 기간, 약관 제10조 1항 범위, Vercel 저장 국가.
