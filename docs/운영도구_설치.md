# 운영 도구 설치 — erp-project 전용 안내

운영 도구(WY Ops)의 범용 설명은 패키지 저장소의 `README.md`·`MANUAL.md`·`NEW-PC.md`에 있다. 이 문서에는 erp-project에만 해당하는 값과 손일만 적는다. 비밀값·개인 주소는 적지 않는다.

## 1. 패키지 위치

- 지금(R10까지): 저장소 안 `tools/wy-ops`. 설치 명령은 `powershell -ExecutionPolicy Bypass -File tools\wy-ops\install.ps1 <명령>`.
- 분리 뒤(R11 전환·K5 이후): 패키지 저장소(agentTeamPackage)를 `C:\projects\agentTeamPackage`에 clone하고, 그 폴더의 `install.ps1`로 설치한다. 설치 후에는 `"$env:USERPROFILE\.wy-tools\wy-ops\current\install.ps1"`로 부른다. `tools/wy-ops`는 K5 직후 지운다(PACKAGING-PLAN 10장 R11).
- 이 프로젝트가 쓰는 버전은 `.claude/wy-ops.json`의 `wyOpsVersion`(사용자가 정한다).

## 2. 역할 이름

접두사는 `WY-`. 역할 구성과 담당은 `CLAUDE.md` '세션 역할' 표가 원본이다.

- 고정: `WY-pm`, `WY-commit`
- 개발: `WY-backend1`·`WY-backend2`(+보조 `WY-backend3`), `WY-frontend`·`WY-frontend2`
- 그 밖: `WY-planner`, `WY-design`, `WY-browser`, `WY-qa`·`WY-qa2`, `WY-search`(이 프로젝트만 쓰는 조사 전담, 범용 기본 구성에는 없음)

## 3. 새 PC에서 이 프로젝트만의 손일

범용 순서(패키지 `NEW-PC.md` 3장: 원래 PC에서 `export` → 새 PC에서 `restore <zip>`)를 따른 뒤, 아래를 챙긴다.

- [ ] 비밀값 폴더: `C:\projects\worklog-secret\`(`.claude/wy-ops.json`의 `secretsDir`). 묶음에 들어가지 않으므로 원래 PC에서 안전한 방법으로 직접 복사한다. 세션은 읽기만 하고 값을 어디에도 옮기지 않는다.
- [ ] 외부 콘솔 로그인: GitHub, Railway, Vercel, 도메인(가비아). 2단계 인증·Google 로그인은 사람이 한다.
- [ ] `WY-browser`: 전용 Chrome 프로필을 만들고 원격 디버깅 포트 9222(CDP)로 실행하는 바로 가기를 만든다. 그 프로필에서 GitHub·Railway·Vercel에 로그인해 둔다.
- [ ] `WY-qa`·`WY-qa2`: agent-browser는 설치 명령이 함께 설치한다. 자기 세션 이름으로 따로 실행하고 `WY-browser`의 전용 Chrome(CDP 9222)에는 붙지 않는다.
- [ ] 개발 환경: 저장소 README의 버전 표(JDK, Docker, Node 등)를 따른다.
- [ ] 운영 메일 발송 확인용 수신 주소는 사용자가 직접 정한다(저장소에 적지 않음).

## 4. 이 PC의 옛 설치 정리(한 번)

패키지화 전 설치(옛 확장 `erp-project.erp-session-dashboard`, 옛 설치본 `~/.wy-tools/vscode-dashboard`, 옛 승인 위치 `~/.claude/wy-approvals/` 바로 아래의 requests·decisions·used·decisions.log)는 `install.ps1 cleanup-legacy`로 지운다. 목록을 보여 주고 `y`를 받은 뒤에만 지운다. 프로젝트별 승인 폴더는 건드리지 않고, 훅이 아직 옛 설치본을 가리키면 그 항목은 지우지 않는다.

옛 확장으로 되돌려야 할 때(마지막 수단, `cleanup-legacy` 전에만 가능):
1. `code --uninstall-extension wy-ops.wy-ops`
2. 명령 팔레트 `Developer: Install Extension from Location…` → `%USERPROFILE%\.wy-tools\vscode-dashboard`
3. `.claude\settings.local.json`을 설치 전 백업(`settings.local.json.bak-<시각>`)으로 되돌린다(사용자가 직접).
4. `Developer: Reload Window` 후 `WY-pm`에 알린다.

옛 설치본을 지운 뒤에는 `install.ps1 rollback` → Reload를 쓴다.
