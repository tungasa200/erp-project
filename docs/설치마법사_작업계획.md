# 설치 마법사 작업 계획

작성: WY-planner, 2026-10-10. 상태: **목업 승인(2026-10-10), 구현 전.** 결정: D-170(카드 20261010-2240, 2026-10-10 22:03 답), D-171(목업 승인·받는 법·폴더 허락·GitHub 건너뛰기·관리자 권한, 카드 20261010-2350, 22:25 답). 지시: WY-pm. 범위: agentTeamPackage(wy-ops 패키지) 0.9.0. 제품(WY) 요구사항정의서·작업계획서는 개정하지 않는다.

## 1. 목표

개발 지식이 적거나 없는 사람도 단계만 차례로 따라가면 혼자 설치를 끝낼 수 있게 한다(사용자 요구 2026-10-10). 지금은 처음 설치가 터미널 명령 2줄과 손일 안내 읽기라 비개발자는 혼자 하기 어렵다.

| 실패 안내, 마지막 점검(doctor) 결과 표시 | 설치 로직 변경: `install.js`는 그대로, 마법사는 명령 인자로 부르는 앞단 |

## 3. 화면 기준(pm 정리, 사용자 요구에서)

1. 터미널을 보이지 않는다.
2. 개발 용어(접두어·스택·역할 수 등)는 기본값으로 정하고 '고급'에만 둔다.
3. 필수 도구는 묻지 않고 설치하며 진행 막대로 보여 준다.
4. 계정 단계는 '브라우저 열기' 버튼 + 끝났는지 자동 확인.
5. 실패하면 쉬운 말 안내와 '다시 시도'·'로그 저장' 버튼.
6. 마지막은 점검 결과를 초록·노랑으로 보여 주고 'VS Code 열기'.
7. 설명은 짧게(사용자 요구 2026-10-10). 개발 지식 없이 바로 이해하기 어려운 용어에만 열고 닫는 도움말을 두고, 기본은 닫힘.

## 6. 검증

- 새 Windows 사용자 계정에서 받는 곳 안내문대로 Git 설치·clone → `setup.cmd` 더블클릭 → 'VS Code 열기'까지, clone 뒤로는 터미널 입력 없이 끝남.
- 이미 도구가 있는 PC에서 다시 실행해도 깨지지 않음(있는 도구는 건너뜀).
- 단계마다 일부러 실패시켜(네트워크 끊기, 로그인 취소, 폴더 허락 기록 실패) 쉬운 말 안내·다시 시도·로그 저장·대체 경로가 동작.
- GitHub 건너뛰기 → 마침 화면 노랑 + 할 일 카드.
- 100%·125%·150% 화면 배율에서 글자·버튼이 흐리거나 잘리지 않음.
- 마지막 점검 결과가 `install.ps1 doctor` 결과와 같음.

## 7. 위험

| 위험 | 영향 | 대응 |
|---|---|---|
| clone이 먼저 필요(D-171 ①, 사용자 선택) | 마법사 전에 Git 설치와 명령 입력이 있어 비개발자 기준에 어긋남 | 받아들인 대가(업데이트가 `git pull`로 쉬움). 받는 곳 안내문에 Git 설치·clone을 그림과 함께 짧게 |
| 폴더 허락을 Claude 설정 파일(`~/.claude.json`)에 직접 기록(D-171 ②) | Claude 내부 형식에 기대므로 업데이트 때 깨질 수 있음, 실행 중인 Claude와 같은 파일을 씀 | 기록 뒤 다시 읽어 확인, 실패하면 Claude 창 Yes로 대체. 쓰기 전 백업 |
| Windows 허용 창(UAC) 반복(D-171 ④) | 프로그램 수만큼(최대 5번) 허용 창이 뜸 | 설치 화면 한 줄 안내. 처음부터 관리자로 실행하면 만든 파일이 관리자 소유가 되어 기각 |
| SmartScreen | 서명 없는 파일이라 처음 실행 때 경고가 뜰 수 있음 | 안내 문서에 '추가 정보 → 실행' 그림. 서명은 공개 배포 때 다시 검토 |
| 다운로드 차단(Mark of the Web) | 차단 표시가 붙은 스크립트가 막혀 마법사가 안 뜨거나 경고 | clone 파일은 대체로 해당 없지만 `setup.cmd`가 시작할 때 `Unblock-File`로 풀기 |
| PowerShell 5.1 인코딩 | BOM 없는 UTF-8 스크립트의 한글이 깨짐 | 마법사 스크립트는 UTF-8 BOM으로 저장, 패키지 시험에 BOM 확인 추가 |
| 고해상도 화면 흐림 | WinForms가 배율 125%·150%에서 흐리거나 배치가 어긋남 | 구현 필수 항목: DPI 인식 설정과 자동 크기 조정, 검증의 배율 시험 |
| 로그인 콘솔 창 | gh·Claude Code 로그인이 콘솔 창을 띄워 '터미널을 보이지 않는다'와 어긋남 | 브라우저 로그인 방식을 쓰고 콘솔은 숨김, 숨길 수 없으면 무엇을 누를지 마법사가 먼저 안내 |
| 도구 설치 실패(권한·네트워크) | 설치가 중간에 멈춤 | 도구별 다시 시도, 로그 저장, 쉬운 말 원인 |
