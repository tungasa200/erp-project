WY 승인 센터 목업

사용자 손이 필요한 일(권한 확인·결정·git·할 일)은 받은 요청에, 세션들이 서로 주고받는 일은 활동에 모읍니다. 카드는 펼치지 않아도 종류(아이콘·색), 우선순위(막대·긴급), 대기 시간을 보여 주고, ‘왜’는 접혀 있습니다. 색은 VS Code 테마 변수를 그대로 따릅니다(다크 프레임은 다크 그레이 테마 기준). 프레임 안은 눌러 볼 수 있고, 프레임을 누른 뒤 j / k 이동, a 처리, x 거부가 됩니다.

1. 편집기 탭 · 다크: 받은 요청, 결정 카드

목록 한 줄: 종류 아이콘 · 제목 · 대기 시간 / 요청 세션 아바타(상태 고리) · 요약 칩 · 우선순위.

2. 편집기 탭 · 라이트/다크: 권한 확인(허용 / 거부)

세션은 이 카드의 결정을 기다립니다. 허용은 이번 한 번만, 15분이 지나면 시간 초과로 처리됨에 남습니다. 다크 프레임은 거부 사유를 쓰는 중.

3. 편집기 탭 · 다크: 활동: 묶음

위 줄은 세션마다 지금 상태(초록 회전 = 일하는 중, 회색 = 대기, 빨강 맥박 = 권한 대기, 점선 = 멈춤). 아래는 작업 ID와 SendMessage 응답 관계로 묶은 이야기: 보고 → 수정 → 재검증이 단계 사슬로 이어집니다. 메시지 글은 접혀 있습니다.

4. 편집기 탭 · 라이트: 활동: 시간 보기

넓은 폭에서만 켜지는 두 번째 보기. 세션마다 한 줄, 가로가 시간. 띠 색이 상태, 화살표가 메시지, 점선 상자가 한 묶음입니다.

5. 편집기 탭 · 다크: 흐름 / 라이트: git 승인 / 빈 상태

git 카드는 브랜치·파일·커밋을 칩으로, 지금까지 거친 단계(구현 → 검증 → 승인 → 실행)를 사슬로 보여 줍니다.

6. 사이드바(340px)

좁은 폭에서는 상세가 목록 자리를 차지하고, 활동은 묶음 보기만 씁니다.

펼치지 않고 보이는 것(OPS-08)

  • 종류: 아이콘과 색. 권한 빨강·자물쇠, 결정 보라·갈래, git 파랑·커밋/푸시, 할 일 주황·체크 원.
  • 우선순위: 행 오른쪽 아래 막대. 긴급(빨강 사각 !), 높음(막대 3), 보통(막대 2). 권한 확인은 늘 긴급, 하루 넘은 카드는 높음.
  • 대기 시간: 행 오른쪽 위. 30분 이상 굵게, 하루 이상 빨강. 권한 카드는 대신 ‘n분 남음’과 남은 시간 막대.
  • 요청 세션은 아바타와 상태 고리로, 요약은 칩(브랜치·파일 수·질문 수·단계 수·막은 곳)으로 보입니다.

활동

  • 세션 상태: claude agents 상태 + 대화 기록(jsonl)의 마지막 동작. 권한 대기는 PermissionRequest 훅이 올린 카드로 판정(waitingFor는 보조).
  • 묶음: 메시지 속 작업 ID(P1-09-09 등)와 SendMessage 응답 관계로 묶습니다. 사슬의 마디는 메시지 하나, 지금 단계는 고리, 다음 단계는 점선.
  • 사슬 마디가 사용자 카드로 이어지면 ‘카드 열기’ 버튼이 받은 요청의 해당 카드로 갑니다.

단축키

  • j / k 이동, Enter 열기, Esc 목록으로
  • a 승인 · 답 보내기 · 했음 · 이번 한 번 허용(카드의 주 행동)
  • x 거부(사유 입력), 1–4 선택지, w ‘왜’ 펼치기, g a 활동, g f 흐름
