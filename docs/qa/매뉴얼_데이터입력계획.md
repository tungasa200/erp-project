# 매뉴얼 가상 데이터 입력 계획 (D-216)

> 2026-10-13 사용자 지시로 2주 입력 계획 중단, 매뉴얼 첫 판 a3c5b78 발행. 아래 3·4절은 중단 전 계획이며 실제 입력은 6절.

작성 WY-qa, 2026-10-12. 근거: docs/매뉴얼_작업계획_v1.md 3·4·6·9·10장, docs/manual/README.md '가상 데이터', D-216·D-217, D-214·D-215. 계정: 운영 매뉴얼 계정(D-217, 값은 저장소 밖 secret.txt). 입력은 모두 앱 화면으로 한다(DB 직접 입력 없음).

## 1. 원칙

- 가상 회사 가나다상사, 사용자 마케팅팀 대리 김우연. 이름은 README의 것만 쓴다. 실제 기업·사람 이름은 쓰지 않는다.
- 통계의 완료 수는 실제 완료 시각(completed_at), 기록 수는 기록 날짜, '마감한 날'은 하루 마감으로 센다. **완료·하루 마감은 그날 실제로 누른다**(지난 날을 채우지 않음). 오늘(10-12)은 기본 데이터만, 완료·하루 마감 없음.
- 주 기록 단위: 근무일 10일, 2026-10-13(화) ~ 10-26(월). 공휴일 없음(10-17·18·24·25는 주말). 하루 입력은 pm의 "오늘 분 입력" 지시 때 한 번에 한다.
- 화면: 1280×800(W)과 390×844(M) 두 크기. 메일이 보이는 칸(사이드바 이름 아래·설정 계정)은 가리거나 찍지 않는다(D-206).

## 5. 가정

1. 오늘 입력은 계정 로그인 상태에서 앱 화면으로만 한다. 계정 이름은 김우연이다(D-217).
2. 완료 처리는 업무 목록·홈의 체크로 하고, 완료 때 '결과 한 줄'을 넣는다(기록 1건이 남음).
3. 같은 날 업무 완료와 직접 기록이 겹쳐도 기록 수는 날마다 3~5건 안이면 된다.
4. 하루 마감 시각 전에 마감하려면 [하루 마감]을 쓰면 된다(홈 띠는 18:00 뒤에 뜨지만 홈 카드 [하루 마감]은 항상 있음 — 오늘 화면으로 확인함).
5. 계획과 실제가 달라지면 이 파일 맨 아래 '실제 입력 기록'에 적는다.
