## 4. 판정

- **통과**: 200~300개(302회차) 월·주 보기에서 끌기·밀기 중 100ms 넘는 프레임 0, CPU 4배에서도 끌기 시작 때 한 프레임(67~83ms)뿐. 첫 렌더링은 1배 0.3~0.9초, 4배 0.5~0.8초
- 관찰(결함 아님): 앱이 한 청크(860.9 kB, gzip 267.8 kB)라 vite가 500 kB 경고를 냄. 화면별 코드 분할은 출시 뒤 후보
- 한계: headless라 화면 합성(GPU) 끊김은 이 값에 덜 드러남. 실기기 확인은 REL 실기기 시험 때
