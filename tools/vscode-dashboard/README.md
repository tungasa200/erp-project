# 세션 현황 대시보드 (VS Code 확장)

VS Code 사이드바에서 메모리, 프로세스 그룹별 사용량, Claude 역할 세션 상태를 읽기 전용으로 본다. npm 의존성과 빌드 단계가 없다.

## 설치

1. 명령 팔레트(Ctrl+Shift+P)에서 `Developer: Install Extension from Location...`을 실행한다.
2. 이 폴더(`tools/vscode-dashboard`)를 고른다.
3. 창을 다시 불러온다(`Developer: Reload Window`). 활동 막대에 '세션 현황' 아이콘이 생긴다.

## 갱신

코드를 바꾼 뒤에는 같은 폴더로 1번을 다시 실행하고 창을 다시 불러온다. 지우려면 확장 보기에서 'ERP 세션 현황'을 제거한다.

## 동작

| 항목 | 출처 | 주기 |
|---|---|---|
| 전체·여유 메모리 | Node `os.totalmem`·`os.freemem` | 5초 |
| 프로세스 그룹 상위 5개 | `tasklist /fo csv /nh` | 15초 |
| 세션 | `claude agents --json --all` | 10초 |

- 패널이 보이지 않으면 폴링을 멈춘다. 위 오른쪽 새로고침 버튼으로 바로 갱신할 수 있다.
- 세션은 저장소 `CLAUDE.md`의 세션 역할 표 순서로 정렬하고, 띄우지 않은 역할은 '없음'으로 보여 준다. 워크스페이스 루트가 저장소여야 한다.
- 여유 메모리가 1GB 미만이면 막대와 문구가 경고색으로 바뀐다. 막대 위의 세로선이 1GB 기준이다.
